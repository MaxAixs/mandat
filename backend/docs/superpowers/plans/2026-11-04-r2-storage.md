# Cloudflare R2 Image Storage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Cloudflare R2 image-storage driver behind a small Upload/Delete contract; no AWS S3 support.

**Architecture:** Consumer-owned `ImageStorage` interface in `internal/service`; concrete S3-API client in `pkg/storage/r2` pointed at the R2 jurisdiction endpoint. Secrets come only from env, bucket/endpoint/public URL from `config.yaml`.

**Tech Stack:** Go 1.27, `github.com/aws/aws-sdk-go-v2/service/s3` + `aws/auth/credentials` (S3-compatible API against R2 endpoint), `github.com/google/uuid` (already present, for safe object keys)

**Spec:** `backend/AGENTS.md` §10 (Image Storage) as adapted: "S3-compatible" is replaced by "Cloudflare R2 only"; all other §10 rules (interface, external config, MIME validation, safe keys, no creds to frontend, cleanup) still apply.

## Global Constraints

- Clean Architecture: domain/service must not import AWS SDK, Gin, pgx; SDK stays in `pkg/storage/r2`.
- Interfaces are defined close to the consumer (`internal/service`); `pkg` provides the concrete type.
- Secrets (R2 Access Key ID, Secret Access Key) come only from env vars, never from `config.yaml` or committed files.
- `gofmt`, `go vet ./...`, `go test ./...` must pass.
- Do not write real credentials into any file; tests use fakes, never live R2.
- Never edit `*_test.go` as primary agent; tests are written by the `test-author` subagent.

## Review Focus

- Oversized upload (e.g. 50 MB body) must fail fast with a classified validation error, not OOM or hang.
- Spoofed content-type (e.g. `.exe` sent as `image/jpeg`) must be rejected by content sniffing, not trusted header.
- Delete of a nonexistent key must not return a hard error that breaks article deletion.
- Empty bucket/endpoint config must fail fast at startup with a clear message, not on first upload.
- Returned public URL must never leak the endpoint credentials or internal key scheme beyond `PublicBaseURL + key`.

### Task 6: Fetch-and-store pasted image URLs (main editor flow)

**Context:** the editor only pastes an image link into `image_url`; the backend downloads it and stores it in R2 under the slug key. Multipart file upload (Task 4) stays as-is. Frontend unchanged.

**Files:**
- Create: `pkg/httpfetch/httpfetch.go` (+ `Config`, SSRF guard)
- Modify: `internal/service/news.go` (URL -> CoverUpload conversion)
- Modify: `cmd/main.go` (wire fetcher)
- Test: `pkg/httpfetch/httpfetch_test.go`, additions to `internal/service/news_r2_test.go` (all via test-author)

**Interfaces:**
- Consumes: `CoverUpload`, `ImageStorage`, `coverKey`, `r2.MaxUploadBytes`.
- Produces: `httpfetch.Config{Timeout time.Duration, MaxBytes int64, MaxRedirects int, AllowPrivate bool}`; `func NewClient(cfg Config) *Client`; `func (c *Client) Fetch(ctx context.Context, rawURL string) (data []byte, mime string, err error)` returning body bytes + sniffed MIME; service `ImageFetcher interface { Fetch(ctx, url) ([]byte, string, error) }`; `(s *NewsService) WithFetcher(f ImageFetcher) *NewsService` (existing constructors untouched, nil fetcher = legacy hotlink behavior).

**Rules:**
- Only `http`/`https` URLs are fetched; anything else in `image_url` stays untouched (legacy).
- A URL under our `coverBaseURL` is already ours: never refetched.
- Fetch happens BEFORE any DB write (clean failure, no orphans): malformed URL/non-image/too-big classify as `errs.ErrInvalidInput`; network/source failures as `errs.ErrServiceUnavailable`.
- SSRF guard: dial-control rejects non-public IPs (10/8, 172.16/12, 192.168/16, 127/8, 169.254/16, ::1, fe80::/10) unless `AllowPrivate` (tests use httptest + `AllowPrivate: true`); 15 s timeout, 3 redirects max, body capped at `r2.MaxUploadBytes`.
- Extension derives from sniffed MIME (jpeg->jpg, png->png, webp->webp, gif->gif); unmappable types fail as invalid input. Fetched bytes convert to `CoverUpload{Body, Filename: "image.<ext>", ContentType: mime}` and flow through the existing upload machinery (slug key, compensation, old-key cleanup).
